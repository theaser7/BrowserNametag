# Browser Nametag 🏷️

**Browser Nametag** — это инструмент для переименования окон браузера на панели задач Windows (Thorium, Chrome, Edge, Brave, Firefox, Opera, Vivaldi, Яндекс Браузер и др.).

---

## 💻 1. Настольное приложение (BrowserNametag.exe) — Рекомендуется

Chromium (включая Thorium) аппаратно дописывает суффикс ` - Thorium` или ` - Google Chrome` в заголовок окна Windows. Нативное приложение напрямую управляет заголовками окон через Win32 API и гарантирует 100% чистый заголовок на панели задач.

### Особенности:
- **Чистое имя на панели задач:** Заменяет заголовок окна Windows (без «Новая вкладка - Thorium» и без суффиксов).
- **3 режима работы:**
  1. *Строго введенный текст* — на панели задач будет отображаться только ваш текст (например, `Thorium`, `Work`, `Dev`).
  2. *Отрезать суффикс браузера* — оставляет оригинальное название страницы, но вырезает ` - Thorium` / ` - Google Chrome`.
  3. *Префикс* — `ВашТекст | Название страницы`.
- **Работа в фоне / трей:** Сворачивается в системный трей возле часов, потребляет 0% CPU и ~10 МБ ОЗУ.
- **Портативность:** Один автономный файл `BrowserNametag.exe` (19 КБ), не требует установки.

### Запуск:
1. Запустите [`BrowserNametag.exe`](BrowserNametag.exe).
2. Введите желаемый заголовок.
3. Нажмите **«Включить замену»**.
4. Готово! Заголовок на панели задач мгновенно изменится. При закрытии крестиком программа сворачивается в трей.

## 🌐 2. Браузерное расширение (Manifest V3)

Для управления названиями самих веб-вкладок внутри браузера:
- Распакованная папка расширения совместима с Chrome, Edge, Brave и Firefox.
- Перехват `document.title` и защита от перезаписи через `MutationObserver`.
